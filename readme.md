# 🚀 Cartão de Visitas Digital - Davi da Silva Santos

Um mini portfólio / cartão de visitas digital minimalista desenvolvido para centralizar meus principais links profissionais, como LinkedIn e GitHub.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação da página.
* **CSS3:** Estilização, layout responsivo com Flexbox, efeitos de hover e iluminação (*glow*).
* **Google Fonts:** Utilização da tipografia [Inter](https://fonts.google.com/specimen/Inter).

---

## 🎨 Funcionalidades e Efeitos

* **Design Minimalista:** Tema escuro com destaque visual para os botões.
* **Efeito Neon/Glow:** Utilização de `box-shadow` e `text-shadow` nos elementos interativos.
* **Micro-interações:** Animação suave com `transform: scale()` ao passar o mouse sobre os botões.
